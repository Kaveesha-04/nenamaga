# NenaMaga - Premium Education Portal 🎓

Welcome to **NenaMaga**, Sri Lanka's premium education portal designed to provide high-quality learning resources including past papers, comprehensive notes, and interactive video lessons.

## 🌟 Features

- **Rich Resource Library**: Access a wide collection of past papers, study notes, and video materials.
- **Premium User Interface**: Modern, responsive design built with Tailwind CSS.
- **Dark Mode Support**: Seamless toggle between light and dark themes for comfortable reading.
- **Secure Authentication**: Built-in Firebase Authentication for secure and seamless access.
- **Optimized Performance**: Fast loading times with optimized assets and Firebase Hosting.

## 🛠️ Technology Stack

- **Frontend**: HTML5, Vanilla JavaScript, [Tailwind CSS](https://tailwindcss.com/)
- **Backend & Hosting**: [Firebase](https://firebase.google.com/) (Authentication, Hosting)
- **Icons & Typography**: Google Fonts (Inter, Noto Sans, Iskoola Pota, Lexend)

## 🚀 Getting Started

### Prerequisites

To run this project locally, you can use any local development server (e.g., VS Code Live Server, Node `http-server`, or Python's `http.server`).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Kaveesha-04/nenamaga.git
   ```
2. Navigate into the directory:
   ```bash
   cd nenamaga
   ```
3. Open `index.html` in your browser or start a local server.

### Firebase Configuration Setup

For security, the Firebase API Key is not included in the repository. To fully enable authentication features:

1. Create a Firebase project in the [Firebase Console](https://console.firebase.google.com/).
2. Get your Firebase configuration settings.
3. Open `index.html` and `U1.html` and replace `YOUR_API_KEY_HERE` with your actual Firebase API Key.
